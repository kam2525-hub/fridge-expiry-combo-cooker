# 冷蔵庫の余り物ごちゃまぜ一撃レシピメーカー

冷蔵庫の奥で眠っている半端な食材を3つ選ぶだけで、今すぐ作れる美味しいおかずのレシピを瞬時に組み立てるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/fridge-expiry-combo-cooker/）。
2. 画面の指示に従って操作します。
